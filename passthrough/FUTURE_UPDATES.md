# Future Updates & Enhancements

This document outlines planned features, improvements, and updates for the XRCapt Passthrough Mixed Reality applications.

---

## 🎯 Phase 1: Core ML Integration (Q1 2026)

### Real Object Detection
- **Replace simulation with actual ML models**
  - Integrate TensorFlow.js for real-time object detection
  - Implement MediaPipe for person/pose detection
  - Add YOLOv8 or MobileNet for multi-object recognition
  - Support for detecting: cars, humans, animals, buildings, landmarks

- **Facial Recognition (Privacy-Focused)**
  - Local face detection and recognition
  - Encrypted facial data storage
  - User consent management
  - Privacy controls and data deletion options

### Enhanced Detection Capabilities
- **Scene Understanding**
  - Depth estimation using Quest 3S sensors
  - Spatial mapping of environment
  - Object size estimation
  - Distance measurement to objects

- **Landmark Recognition**
  - Integration with geolocation APIs
  - Famous landmark database
  - Historical information overlays
  - Navigation assistance

- **Real Camera Integration**

  - Burst mode for multiple captures

- **Photo Organization**
  - Auto-tagging based on object detection
  - Search and filter capabilities
  - Timeline view of captured moments
  - Smart albums (by object type, location, date)

### Video Recording
- **Video Capture**
  - Record short video clips in MR
  - Time-lapse mode
  - Slow-motion capture
  - Video trimming and editing

- **Sharing Options**
  - Export photos/videos to Meta Quest library
  - Cloud backup integration (optional)
  - Social media sharing
  - QR code generation for quick sharing
